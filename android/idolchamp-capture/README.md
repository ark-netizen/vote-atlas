# 아이돌챔프 실제 앱 수집기 (검증용)

이 프로젝트는 AAA 같은 특정 시상식만 수집하는 도구가 **아닙니다**. 아이돌챔프 앱 \`com.nwz.ichampclient\`에 실제 휴대전화로 접속하여, 표시되는 투표 목록·각 부문·투표 상세·후보·리워드 화면을 기록하는 **앱 자체 수집 경로**입니다.

Android 11 이상 기기가 필요합니다. Galaxy S10e Android 12에서도 설치 가능한 설정입니다. PC에 USB를 계속 연결할 필요가 없으며, GitHub Actions에서 APK를 빌드하므로 업무용 PC에서 PowerShell을 실행하지 않아도 됩니다.

## 설치·실행

1. 저장소의 Actions > **Build IdolChamp physical-device capture APK** > 최신 **성공** 실행으로 이동합니다.
2. 아래 Artifacts의 \`idolchamp-ondevice-collector-apk\` ZIP을 갤럭시에서 내려받고 압축을 해제한 후 \`app-debug.apk\`를 설치합니다. 설치 출처 허용 메시지가 표시되면 **직접 만든 GitHub 빌드 파일인지 확인**한 뒤 허용합니다. 빌드가 성공하기 전에는 설치를 진행하지 마세요.
3. 앱 \`Vote Atlas - IdolChamp 수집\` 실행 > **접근성 수집 서비스 활성화** > Android 설정의 설치된 앱/설치한 서비스에서 동일 이름을 찾아 활성화합니다. 접근성 권한은 화면 정보를 읽을 수 있는 높은 권한이므로 사용 중에만 활성화하세요.
4. **아이돌챔프 앱 열기** > 투표 탭 > 앱에서 제공하는 각각의 투표 부문을 이동합니다. 목록과 투표 상세 및 리워드 화면을 확인하면 보이는 UI 텍스트가 기록됩니다.
5. 목록이 길다면 \`자동 스크롤\`을 켭니다. 이 기능은 현재 스크롤 가능한 화면만 최대 18회 아래로 넘기고, **탭이나 개별 투표를 클릭하지 않습니다**. 부문 변경 시 횟수를 초기화합니다.
6. 원문 이미지까지 필요할 때만 스크린샷 옵션을 켭니다. 계정 정보 등이 같이 저장될 수 있습니다.
7. 수집기 화면에서 **수집 결과 ZIP 내보내기**를 눌러 파일을 저장하고, 여기 채팅에 첨부하면 앱 UI별 실제 수집 내용을 분석하고 다음 자동 탐색 로직을 검증할 수 있습니다.

## 보안·수집 범위

- 앱 자체에는 인터넷 권한이 없고, 화면 정보와 선택적 스크린샷은 휴대전화의 앱 전용 저장소에만 보관됩니다. 사용자가 내보내기 버튼을 누르기 전에는 외부로 보내지 않습니다.
- 접근성 서비스는 아이돌챔프 패키지로 한정합니다. 투표·결제·광고 시청·동의·로그인 화면 버튼을 자동으로 누르지 않습니다.
- **화면 수집 = 전체 앱 데이터 수집 성공이 아닙니다.** 사람이 열지 않은 탭, 접근성에서 제공되지 않는 웹뷰/캔버스 콘텐츠, 로그인 필요 화면 등은 누락될 수 있습니다.
- 내보낸 JSONL에는 \`source_compared=false\` 및 \`lineup_complete=false\`를 표시합니다. 실제 앱과 대조하기 전에는 운영 중인 \`dist/data/events.json\`에 합치지 않습니다.
- 사용을 마친 뒤 접근성 서비스를 끄고, 앱에서 화면 기록을 삭제할 수 있습니다.
- 임시 debug APK는 첫 실기기 검증 전용입니다. 정식 배포 전에 화면 수집 정확도, 패키지 설치, 보안 검토가 필요합니다.

## 빌드

GitHub Actions: \`.github/workflows/build-idolchamp-ondevice.yml\`.

프로젝트는 Java/Android Gradle Plugin 기반이며 클라우드에서 무료로 빌드합니다. 사용자 개인 계정이나 제3자 API 키는 사용하지 않습니다.
